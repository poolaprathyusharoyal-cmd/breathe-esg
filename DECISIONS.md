# DECISIONS

Technical Decisions:
- React was used for frontend development because it provides a fast and interactive UI.
- Django REST Framework was used for backend APIs and CSV processing.
- SQLite was used as the database for simplicity and rapid prototyping.
- CSV upload was selected because enterprise ESG data is commonly exported in CSV format.
- The dashboard was designed to display uploaded emission records in tabular format.

Prototype Decisions:
- Focus was given to core functionality instead of advanced UI features.
- Sample emission data was used for testing and validation.
