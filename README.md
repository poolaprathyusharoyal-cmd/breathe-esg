# Breathe ESG Assignment

## Overview

This project is a prototype ESG Emission Dashboard built using Django REST Framework and React.

The application supports:

* CSV upload for emission records
* Emission dashboard visualization
* Backend API integration
* Storage of emission data using SQLite

## Tech Stack

* React
* Django REST Framework
* SQLite
* Vite

## Features

* Upload emission CSV data
* View uploaded records in dashboard
* REST API integration
* Emission data normalization prototype
